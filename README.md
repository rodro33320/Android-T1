# Android T1

Repositorio correspondiente a la primera parte del trabajo de desarrollo de aplicaciones Android.

## Contenido

En esta primera parte se incluyen los ejercicios y proyectos desarrollados durante el aprendizaje de **Android y Kotlin**, utilizando **Jetpack Compose**.

### Proyecto incluido

* **Birthday Card App**

  * Aplicación básica desarrollada con Kotlin y Jetpack Compose.
  * Uso de componentes de interfaz.
  * Diseño de una tarjeta de cumpleaños.
  * Organización básica de un proyecto Android.

## Tecnologías utilizadas

* Kotlin
* Android Studio
* Jetpack Compose
* Material Design

## Objetivo

Aplicar los conceptos básicos de desarrollo de interfaces Android utilizando **Kotlin y Jetpack Compose**, siguiendo los ejercicios prácticos de la ruta de aprendizaje.
